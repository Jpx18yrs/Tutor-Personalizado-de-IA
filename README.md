# ¡Primero Consigue tu Key!
1- Busca "Google AI Studio" en tu navegador y dale click al primer enlace. 

2- Inicia sesion y en las 4 herramientas que aparecen arriba de tu perfil de Google, dale click a la llave.

3-En la parte superior derecha le das a "Crear clave de API" Pones el nombre de tu preferencia y después copias la clave de API.

# Iniciar Chat De IA 🤖
1-Abre tu IDE Y mueve el archivo .py al editor de codigo de tu IDE y en la linea 4 donde dice "TU_API_KEY_AQUI" Pon tu API Key que sacaste de Google AI studio.

2-En la terminal escribe "Python (Dejas un espacio y arrastras el archivo TutorPersonalizado.py a la terminal)"

3- ¡Inicia la conversacion!
